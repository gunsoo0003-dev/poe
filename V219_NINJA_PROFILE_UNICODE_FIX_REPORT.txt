FIXLGS POE2 / PoB V219 - poe.ninja character URL compatibility fix

  /poe2/builds/{league}/character/{account}/{character}

  The affected user link uses:
  /poe2/profile/{account}/{league}/character/{character}
  V218 rejected this before fetching character data, regardless of character language.

  - Extract account/league/character at correct path positions.
  - Decode non-ASCII URL path segments (Korean/Japanese/Chinese etc.) exactly once.
  - Keep the strict HTTPS poe.ninja allowlist and reject malformed/unrecognized paths.
  - Update the form placeholder to show the profile URL pattern.
  - No changes to filter, PoB item parsing, stats, or snapshot API handling.
