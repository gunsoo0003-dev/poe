[수정 전 예방 점검 원칙]
1. V213 PoB 소스, 데이터, 엔진 보존. 필터 관련 TSX/TS 및 팝업 CSS 외 수정 금지.
2. 사용자 변경이 없으면 NeverSink 원본을 바이트 그대로 유지.
3. 사용자가 조작한 항목만 정확히 override하고, 원본 조건부 표시를 사운드 변경만으로 강제 Show/Hide 하지 않음.
4. 명시적 ON/OFF는 NS 조건부 기본 OFF/ON과 구별해 로컬 저장본에도 남김.
5. 무효 사운드·기본 규칙 미매칭은 침묵하지 않고 생성 중지 및 대상 표시.
6. 0~6단계와 필터 규칙 우선순위 충돌 사례를 구분해 검사하고, 게임에서 검증하지 못한 사항은 정상 판정 금지.

[발견 및 수정한 위험]
A. GemLevel 19 등 비교 연산자가 없는 NeverSink 숫자 문법을 등호로 해석. 알 수 없는 문법은 무조건 참으로 간주하지 않음.
B. 미가공 젬의 조건부 체크값(false)과 명시적 Hide(false)를 구별하도록 visibilityExplicit 상태 추가. NS 상태는 그대로, 명시적인 Show/Hide는 BaseType+GemLevel로 우선 규칙 생성. 조건부 기본 OFF에는 '완전히 숨김' 단축 버튼 추가.
C. 젬/경로석의 사운드만 변경한 경우 원본 Show의 GemLevel/WaystoneTier, AreaLevel 조건을 유지한 복제 규칙을 원본 규칙 바로 앞에 삽입. 원본 Hide는 그대로 Hide 유지.
D. 일반 장비의 원본 개별 BaseType 규칙이 없는 경우, 해당 Class의 원본 Show 규칙을 필요한 BaseType과 Rarity Normal로 정확히 제한해 조건부 복제. 원본 레벨/지역 조건 유지.
E. 일반 장비의 명시적 OFF와 원본 조건부 OFF를 구분하도록 normalGearExplicit 추가. 기존 저장본은 해당 필드가 없으면 원본 동작 그대로.
F. 레어/매직 선택 단계 모드의 fallback Hide 적용 범위를 선택한 Class만이 아니라 관리대상 전체 장비 Class로 확장. 선택한 단계×선택한 Class만 Show.
G. 최고 엄격도 6단계에서 #Show로 주석 처리된 고유 특출난 과퀄리티/과소켓 원본을 사용자 커스텀에 한해 활성화. 체크 해제의 원본 복귀 정책 유지.
H. NeverSink 상위 섹션(2900 등)과 하위 섹션(2901~ 등) 매칭을 정상 처리.
I. 연결 안 된 개인 MP3 등은 오류를 띄우고 필터 다운로드 중단. 최종 필터에서 참조하는 소리 파일만 ZIP에 포함.
J. 폴더 직접 설치: 클릭 → 경로 안내 → 문서 시작. 선택 폴더 이름이 Path of Exile 2가 아니면 경고 후 사용자가 확인해야 저장.
