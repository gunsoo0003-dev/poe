- **영향 파일**: `src/app/page.tsx`, `src/app/globals.css`, `HANDOVER.md`. 필터/PoB 내부 로직, 공식 영상 데이터 소스, Cloudflare/도메인 설정, NeverSink 원본과 계산 엔진은 건드리지 않았다.
