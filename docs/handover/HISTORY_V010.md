FILTER/POB는 실제 Next Link로 유지하며 동일 크기의 금속 프레임/글로우 카드 및 직접 그린 SVG 아이콘을 사용한다. MARKET/GUIDES/영상 섹션의 배경과 폭을 넓히고 영상 4개 원본 소스·재생 컴포넌트는 유지했다.
