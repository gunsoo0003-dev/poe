## 영상 자동재생 확인 — 필수

- **`index.html` 파일을 직접 더블클릭하면 유튜브 자동재생이 제대로 되지 않을 수 있다**. YouTube는 HTTP Referer 정보를 요구하기 때문이다.
- ZIP을 풀고 동일 폴더의 **`영상미리보기.cmd`를 더블클릭**하면 Windows에서 일시적인 HTTP 주소를 열도록 준비했다. Node.js가 있으면 기존 Node 서버를, 없거나 실패하면 기본 PowerShell 서버를 사용한다(추가 설치 필요 없음). 임시 서버 창을 닫으면 종료되며 상시 서버/유료 API는 없다. 이 Windows 더블클릭 동작과 실 유튜브 스트리밍은 환경상 아직 미검증.
- V015는 실제 YouTube의 `PLAYING` 신호가 오기 전까지 영상 재생 성공으로 보이지 않게 수정했다. 오류 발생 시 화면의 오류 코드와 상태 문구를 보고할 수 있다. 153이면 HTTP Referer/임베드 식별 오류 가능성을 먼저 확인한다.
- 최신 공식 영상 자동 갱신은 ZIP 자체에서 계속 실행되는 기능이 아니다. `.github` 예약 스크립트를 승인된 저장소·배포에 실제 연결하는 단계가 별도로 필요하다.

V003 로컬 WebP 방식과 달리 외부 의존성이 있으므로 **운영 반영 전 아이콘 로컬 파일 확보·교체·렌더 검증이 필요**하다. 기능, 데이터 및 유료 API와는 관련 없다.

- **실영상 연결 방법(승인 이후)**: `index.html`의 7번 섹션 `data-youtube-id=""` 3곳에 각각 정확한 유튜브 영상 ID 11자리를 입력한다. 세 ID가 모두 유효한 형식이면 섹션에 진입할 때 YouTube IFrame API를 지연 로드하고 한 번에 한 영상만 음소거로 재생한다. 종료 시 1→2→3→1 자동 전환, 사용자 소리 켜기/끄기 가능, 다음 영상 자동 음소거. **ID 형식 통과는 영상 접근/임베드 허용 보장이 아니다.** 실제 HTTPS 배포 환경·실영상에서 자동재생/오류 153/기기 정책을 반드시 재검증한다. YouTube API 키·서버·MP4 다운로드는 필요 없다.
- 상단 비공식 개인 시안 안내 띠·푸터 안내 문장·에디션의 시안 안내를 화면에서 삭제했고 브라우저 탭 제목을 `FIXLGS POE2`로 변경했다. 다른 섹션(8번 이후 포함) 및 메뉴의 디아블로 IV 참고 문구는 그대로이며 후속 변경은 사용자 지시 전까지 금지한다.
- **기능 및 링크는 아직 미연결:** FILTER 메인은 기존 디아블로 외부 주소, FILTER 보조는 `#welcome`, POB 두 버튼은 `#overview` 임시 링크다. 현재는 디자인 시안이며 실제 서비스인 것처럼 배포하지 않는다.
- 개인 시안 안내를 화면에서 없앴지만, 팬 콘텐츠 이미지의 공개·상업적 사용 가능 범위는 별도 확인 필요. 이번 변경은 정식 서비스 공개 승인 아님.

## V016 — Windows 미리보기 실행 오류 수정
- `영상미리보기.cmd`를 **Windows 배치파일 형식(ASCII·CRLF)**으로 다시 작성했다. 기존 LF 전용 줄바꿈에서 실행 시 문구 일부가 명령어로 해석된 오류를 방지한다.
- Windows에서는 ZIP을 먼저 **압축 해제**하고 최상위 폴더의 `영상미리보기.cmd`를 더블클릭한다. Node.js가 있으면 기존 `scripts/preview-server.mjs`, 없으면 Windows PowerShell `scripts/preview-server.ps1`을 사용해 **127.0.0.1 임시 HTTP** 미리보기를 실행한다.
- 검은 창을 닫으면 미리보기도 종료된다. 브라우저가 자동으로 열리지 않으면 창에 표시되는 `http://127.0.0.1:포트/index.html` 주소를 직접 열어본다. `index.html`만 더블클릭하면 `file://`라 유튜브 임베드 오류 153이 발생할 수 있다.
- Windows 더블클릭과 실제 유튜브 영상 재생은 아직 실기기에서 미검증. **이 수정은 임시 서버 실행 오류 수정이며 실제 영상 자동재생 성공 확인은 별도**이다.
