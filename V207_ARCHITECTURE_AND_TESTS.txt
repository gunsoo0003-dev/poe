FIXLGS POE2 V207 - independent weapon-set snapshots

Root: /pob
PoB original Lua calculation code: unchanged.

Architecture
- pobCompare.ts runs a fresh original PoB XML build for every comparison request.
- Before equipping any simulated item, the engine calculates immutable Set I and Set II baseline snapshots.
- After all replacements are equipped, PoB calculates a separate Set I and Set II simulated snapshot.
- A CURRENT set selector only chooses an existing original snapshot; it cannot edit the engine.
- A SIMULATION set selector chooses the corresponding simulated snapshot and pairs it with the SAME original set when showing deltas.
- Both sets' weapon names and DPS are visible at once in each pane.
- Weapon overrides have physical keys (weapon-set-1, weapon-set-2); a tab change cannot move an override.
- The secondary skill uses the character's original weapon set, not a brute-force attempt on both sets.
- No result falls back to ninja DPS when reporting PoB MAIN SKILLS.
