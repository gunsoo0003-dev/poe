V125 NORMAL VISIBILITY RESOLVER AUDIT

Scope
- Fix NORMAL BaseType checkbox linkage only, based on the currently selected NeverSink filter.
- Preserve Unique linkage, Rare/Magic virtual modes, Exceptional priority, presets, sound/custom export logic.

Root cause
- Previous normal baseline used the generic classifier.
- Quality/socket/AlwaysShow/endgame Hide Layer rules were all collected together, so most normal BaseTypes became `conditional`.
- UI treated every `conditional` entry as checked, making NORMAL look unchanged between strictness levels.

Fix
1. Added a dedicated normalBaselineInfo resolver in scripts/build-neversink-baseline.cjs.
2. NORMAL checkbox state is now resolved independently from conditional NS metadata:
   - Active exact BaseType Show/Hide in sections 1102~1106 => checkbox follows that rule.
   - Otherwise section 1200 normal/magic Hide Layer first active Show/Hide => checkbox follows that fallback.
   - Quality/socket/corruption/AlwaysShow decorators are excluded from the checkbox decision and remain internal NeverSink behavior.
3. Baseline entries can now carry `enabled: boolean`.
4. FilterCustomizer baselineEnabled() uses explicit `enabled` when present; all other categories keep their previous Show/Hide/Conditional behavior.
5. Existing normal importance resolver remains unchanged.
