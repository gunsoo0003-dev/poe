수정 1. 사운드 선택 시 실제 Show 규칙과의 연결 보완
- NeverSink 원본의 sourceSection 메타데이터 밖에 있는 BaseType은 전역 규칙에서 확인
- BaseType 부분 문자열(예: "Lesser")을 사용하는 플라스크는 Class/AreaLevel/Quality 조건을 유지한 복제로 처리
- 원본에서 BaseType 개별 목록이 아닌 Class(호신부·맵조각·탐험일지 등)로 처리하는 경우에는 해당 Show 규칙을 좁혀 복제
- 기존 Hide 규칙에는 사운드를 붙여도 재생되지 않으므로 사운드 단독 변경에서는 Hide 블록을 복제하지 않음
- 원본 NS 조건부 가시성을 사운드 변경만으로 임의로 바꾸지 않음

수정 2. 원본이 숨기는 아이템의 사용자 선택 처리
- 특정 엄격도에서 사운드 단독 변경이 가능한 원본 Show 규칙이 없다면 사운드 선택 즉시 안내
- '표시 ON + 사운드' 변경에 동의한 경우만 visibilityExplicit=true 적용
- 거절 시 해당 변경은 수행하지 않음
- 예전 저장본에 불가능한 조합이 남아 있으면 저장/다운로드 시점에도 동일한 복구 선택을 제공
- 설치 중 복구한 명시적 표시 상태는 저장 슬롯에도 함께 보존
