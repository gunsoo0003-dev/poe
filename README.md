# FIX PoB MOCKUP V002

디자인 1차 시안용 더미 프로젝트입니다.

## 포함
- 기존 FIX PoB 랜딩 화면
- 캐릭터 불러오기 버튼 클릭 시 본게임 더미 화면 진입
- 1920x1080 / 브라우저 100% 기준 상단 캐릭터 영역을 한 화면에 가깝게 구성
- 좌측 EQUIPMENT + BASE JEWELS
- 우측 STATS + MAIN SKILLS TOP2
- 아래 스크롤 영역: ALL SKILLS + 비교 안내 + 변화 후 STATS
- 장비/주얼 클릭 가능한 더미 인터랙션
- 실제 GGG API / PoB2 / 거래소 링크 파싱은 아직 미연결

## 실행
npm install
npm run dev

http://localhost:3000

※ 현재 버전은 디자인 검수용이며 실제 계산값/아이템 데이터는 더미입니다.
