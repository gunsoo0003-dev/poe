V110 · NeverSink checkbox rule correction

확정 원칙
1) 체크박스는 NeverSink의 Show/Hide 결과를 뜻하지 않는다.
2) 선택한 NeverSink 원본에 해당 UI 항목의 규칙이 존재하면 체크한다.
3) Show / Hide / 조건부 규칙은 모두 '원본 규칙 존재'이므로 체크 상태다.
4) 원본 매칭이 없을 때만 비체크다.
5) FIXLGS가 편의상 만든 가상 규칙(레어/매직 편의 단계, 일반 82~78 레벨 규칙 등)은 최초 비활성이다.
6) 사용자가 체크/중요도/사운드를 바꾼 경우에만 override다.
7) 목록에 없는 NeverSink 규칙은 원본 파일에 그대로 남겨 둔다.
8) 아무것도 커스텀하지 않으면 선택한 NeverSink 원본 .filter가 그대로 결과다.

V109에서 제거한 잘못된 동작
- Show=체크 / Hide=비체크 해석 제거
- 조건부/매칭없음에 item checkbox indeterminate(중립) 표시 제거
- NS 표시/NS 숨김/NS 조건부 라벨을 체크 의미와 혼동하지 않도록 NS 원본으로 통일
