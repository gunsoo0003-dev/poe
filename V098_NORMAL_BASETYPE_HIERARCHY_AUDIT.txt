V098 NORMAL BASETYPE HIERARCHY AUDIT
====================================

목표
- NORMAL(흰템)을 Class 1줄이 아니라 큰 카테고리 > 실제 BaseType 하위목록으로 표시
- 상위 카테고리 체크박스로 하위 BaseType 전체 ON/OFF
- 개별 BaseType 각각 표시/숨김
- 중요도 커스텀은 개별 BaseType에만 적용
- 화면에서는 한국어명을 중심으로 표시하고 영문 BaseType은 내부 식별값으로 유지

반영 구조
- NORMAL_GEAR_GROUPS 추가
- 기존 프로젝트에서 이미 검증해 둔 드롭 BaseType/한국어 매핑을 재사용
  · 고유 방어구 BaseType 데이터: 갑옷/투구/장갑/장화/방패/버클러/집중구
  · 고유 무기 BaseType 데이터: 한손 철퇴/양손 철퇴/활/석궁/육척봉/지팡이/셉터/마법봉/창/부적
  · 기타 고유 BaseType 데이터: 목걸이/반지/허리띠/화살통
- 동일 BaseType은 카테고리 내부에서 1개로 중복 제거

현재 UI에 연결된 BaseType 수
- 무기 81
- 방어구 208
- 장신구/화살통 44
- 총 333

주의
- 이번 V098은 기존 프로젝트 내부에서 이미 검증된 BaseType을 NORMAL 계층 UI에 연결한 버전이다.
- '고유가 존재하지 않는 일반 전용 BaseType'까지 현재 시즌 전체를 완전 보강하는 라이브 데이터 감사는 별도 단계로 남아 있다.
- 필터 엔진 다운로드 버튼은 기존과 동일하게 아직 NEXT 상태이므로, 이번 변경은 에디터 UI/상태 구조 범위다.

검증
- TypeScript 소스 파싱 확인: 문법 오류 없음.
- 전체 Next.js build는 실행 환경에서 npm 의존성 설치가 시간 제한으로 완료되지 않아 미실행.
