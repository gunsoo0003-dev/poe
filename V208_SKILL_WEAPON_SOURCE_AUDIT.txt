FIXLGS POE2 /pob — V208 skill-by-weapon-set source separation

REASON
In V207, calculateComparison.capture() calculated Whirling Slash once in the character's original weapon set II and copied its DPS into BOTH Set I and Set II snapshots. The page then assigned a displayed 'Set' label by inference from mainSocketGroup, NOT by source-of-calculation. Selecting Set I thus showed Twister (I) and Whirling Slash (II) in one pane.

FIX
- Every measured skill stores actual PoB group index, physical weapon set, group names, slot and engine DPS.
- Only a measurement obtained in the selected physical set is stored in that set's snapshot.
- Secondary skills are calculated in the original engine weapon set only (an unverified alternate set is not automatically brute-forced).
- MAIN SKILLS filters measurements to those directly obtained for the selected set. Set label is taken from the actual measurement; no DPS copied across sets and no poe.ninja DPS fallback.
- Skill deltas require the SAME measured group, weapon set, and slot in the before and after snapshots.
- 'All Skills' raw poe.ninja figures are explicitly marked reference values; they are not PoB2 per-set calculations.
- Original PoB2 item, modifier, DPS and weapon-set calculation code is unchanged.
